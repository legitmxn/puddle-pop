# Puddle Pop

A tiny, cheerful obstacle-racing game for two pals. Hop over wobbly logs, giant mushrooms, and runaway teacups on the way to the flower.

## Play

Open `index.html` in a modern browser. For the two-player keyboard version, use `A` / `D` to move Pip and `W` to hop; use the arrow keys to move and hop Boo. On a phone or tablet, the touch controls move Pip. Press **Race again** whenever you want another go.

This is a small local multiplayer prototype: both players share one screen and keyboard/device. Online matchmaking and remote multiplayer are not included.

## Publish

The included GitHub Actions workflow publishes this folder to GitHub Pages when changes are pushed to the default branch. In the repository's **Settings → Pages**, choose **GitHub Actions** as the build source. The published path is `/<repository>/` unless a custom domain is configured.
